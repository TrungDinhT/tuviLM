# Agent instructions

## Editing policy

- **Do not** change application code, tests, documentation, or plan files **unless the user explicitly asks you to** (e.g. “implement X”, “apply that patch”, “update AGENTS.md”).
- When a change seems appropriate, **describe the intent only** (what to change, where, why, rough approach) so the user can verify.
- **Ask for confirmation** and **wait for explicit approval** before modifying files when you are proposing work—not executing an explicit edit request.

This overrides generic “just fix it” habits: silent edits are not allowed without clear user consent.
